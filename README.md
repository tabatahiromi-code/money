# こつこつ｜家計簿

文字を読みやすく、操作を見つけやすくまとめた日本語の家計簿です。

- 収入・支出の登録、編集、削除、口座・カード名の記録
- 締め日に合わせた月次集計、カテゴリ別グラフ、月ごとの予算
- 設定ページで締め日を変更（1〜30日・月末）、設定もバックアップ・復元に対応
- ポップアップの電卓、計算結果の金額欄への反映
- 銀行・カードのPDF明細から日付・摘要・金額を取り込む
- レシート写真の日本語・英語OCRから日付・店名・合計金額を抽出
- OFXの銀行・カード明細（SGML / XML）の取り込み、取引IDによる重複候補の判定
- CSVの列指定、UTF-8・Shift_JIS・UTF-16対応、収入／支出が混在する明細にも対応
- 取込前の編集・行の選択・重複候補の表示
- CSV出力、JSONバックアップ・復元

## 起動

Node.js 20以降を使用してください。

```sh
npm install
npm run build
python3 -m http.server 8000 --directory dist
```

ブラウザで http://localhost:8000 を開きます。依存するPDF/OCRエンジンと言語データはbuildでdist/vendorに用意します。言語データはダウンロード時にSHA-256を検証します。サーバーへはdistの内容を配信してください。

## 設定と締め日

家計簿上部の「設定」から、毎月の締め日を設定できます。初期設定は月末（1日〜月末）です。15日締めなら毎月16日〜翌月15日を集計し、締め日がある月を「○月分」と表示します。たとえば11月分は10月16日〜11月15日です。画面にも開始日・終了日を明示します。

収支、カテゴリ別集計、取引履歴、予算の利用額、CSV出力を同じ期間で扱います。記録や明細の取り込み後も、その日付を含む期間へ移動します。29日・30日など、指定した日が存在しない月は月末で締めます。期間に隙間や重なりが生じないよう、次の期間はその翌日から始めます。

既存の取引は日付を保持して再集計します。既存の月別予算は同じ「○月分」の予算として引き継ぎます。設定は家計簿と同じブラウザの保存領域に入り、JSONバックアップ・復元にも含まれます。設定のない旧バックアップは月末締めとして扱います。

## PDF・画像の読み取り

「明細を取り込む」でPDFファイルを選択し、口座・カード名を入力します。PDFは文字を抽出し、文字が少ないページには自動でOCRを使います。「すべてOCR」も選べます。レシート写真は別の「レシートOCR」ボタンから読み取れます。対応画像はPNG・JPEG・WebPです。1ファイル20MB、PDFは1回20ページまでに対応しています。

読み取ったテキストから日付のある取引行を候補として表示します。省略された年、取引の種類、行内の金額の位置を指定できます。PDFの形式や画像の品質によって読み取れない行や誤読が生じます。元の明細と照合して日付・金額・種類・摘要を修正し、取り込む行を選択してください。検出できない取引は手動で行を追加できます。PDF・OCRの候補は初期状態では選択されません。重複候補は日付・種類・金額・摘要・口座名から判断し、同一取引であることを保証しません。

銀行の口座引落とカード利用明細を両方取り込む場合は、二重計上を避けるために不要な行を除外してください。CSVは入出金が別の列、符号付きの金額、収入のみ、支出のみの形式に対応します。自動で金融機関へ接続する機能はありません。

## OFX・CSVの取り込み

「明細を取り込む」でOFXまたはCSVファイルを選び、口座・カード名を入力して内容を確認します。行ごとに日付・摘要・種類・金額を修正し、選択した記録だけを家計簿へ追加できます。

SafariなどでOFXが選択不可にならないよう、ファイル選択時は種類を制限しません。選択後に内容を検査します。拡張子が.txt・.xmlなど、または拡張子のないOFXも内容から識別します。

OFXは銀行・カードのSGML形式（1系）とXML形式（2系）、円（JPY）に対応します。マイナスの金額は支出、プラスは収入として読みます。取引ID（FITID）を口座・金融機関と組み合わせて保存し、同じファイルを再読込した場合や登録後に摘要・口座名を変更した場合にも重複候補を判断します。同じ日付・店名・金額でも取引IDが異なる取引は区別します。取引IDがない行は内容による重複判定に切り替わります。重複候補の選択は初期状態では外れています。外貨、投資用、訂正・削除指示を含むOFXには対応していません。

CSVはカンマ・タブ・セミコロン区切り、引用符付きの摘要や改行に対応します。日付・摘要・金額の列を選び、金額の読み方を「支出のみ」「収入のみ」「符号付き」「入出金が別の列」「収入・支出の種類が別の列」から指定できます。アプリから出力したCSVを再取込する場合は「種類」の列で収支を区別します。

自動の文字コード判定で文字化けする場合は、UTF-8・Shift_JIS・Windows-1252・UTF-16を指定できます。OFXの宣言された文字コードも参照します。1ファイル20MB・10,000取引までです。

## レシートOCR

「レシートOCR」で写真を選択し、文字を認識させます。日付・店名・合計金額を読み取り、候補を表示します。小計・消費税・お預り・お釣りを合計と取り違えないよう、元の写真と照合してください。読み取れない項目は手入力で修正でき、合計以外の金額候補も選べます。照合済みのチェックを入れてから支出として登録します。画像そのものは保存しません。

## 保存とプライバシー

記録はブラウザのlocalStorageに保存します。ファイルのPDF解析・OCRもブラウザ内で処理し、明細やパスワードを外部へ送信する処理はありません。エンジン・言語データは配信元から読み込みます。PDFのパスワードは保存しません。

端末・ブラウザ・URL間の同期はありません。閲覧データの削除で記録も失われるため、バックアップを定期的に保存してください。

## 使用ライブラリ

PDF.js 4.10.38、Tesseract.js 6.0.1、Tesseract.js-core 6.0.0、日本語・英語のtessdata_fastを使用します。各ライセンスはbuildでvendorへコピーします。言語データの配布元は https://tessdata.projectnaptha.com/4.0.0_fast/ です。
