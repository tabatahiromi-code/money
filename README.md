# こつこつ｜暮らしの家計簿

可愛らしくコンパクトな、日本語の家計簿アプリです。

## 機能

- 収入・支出の登録、編集、削除
- 月別集計、カテゴリ別グラフ、月ごとの予算
- 四則演算・かっこ対応の電卓と金額への反映（円単位の正の整数のみ）
- CSV出力、JSONバックアップ・復元
- スマートフォン対応

## 使い方

`index.html` をブラウザで開くと使えます。安定した保存にはHTTPサーバーで配信してください（例：`python3 -m http.server 8000`）。外部ライブラリのインストールは不要です。フォントが取得できない場合は端末のフォントを使います。

## データの保存

記録はアクセスしたブラウザのlocalStorageに保存します。サーバーやGitHubリポジトリへ家計簿のデータを送信する機能はありません。

端末・ブラウザ間の同期はありません。閲覧データの削除で記録も失われるため、バックアップを定期的に保存してください。別のURLで開いた場合も別の保存領域になります。
